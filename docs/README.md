# Overview

Use this documentation to explore and use APIs from products of the Bosch Home Comfort Group.
API availability depends on your specific product, its firmware version and system configuration.

| Product                       | Brand-specific names                                                                  | What you can do                                                       |
| ----------------------------- | ------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| [K 40 RF / MX400](k-40-rf.md) | Bosch Connect-Key K 40 RF, Buderus MX400, and K 40 RF for IVT, Vulcano, and Worcester | Read data from your connected heating system over your local network. |
