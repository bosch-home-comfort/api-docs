# Contributing

Thank you for helping us improve the Bosch Home Comfort API documentation.

## Ways to Contribute

You can contribute by reporting:

- Typographical or grammatical errors
- Incorrect or unclear documentation
- Errors in an OpenAPI definition
- Missing examples or explanations
- Ideas for new or improved documentation

## Start a Discussion

Open a [GitHub Discussion](https://github.com/bosch-home-comfort/api-docs/discussions).
Describe your proposed change. Include the affected file, API, brand, or section
when this information is available.

Before you start a discussion, search the existing discussions for the same
topic. Do not include credentials, personal data, or confidential information.

Maintainers can ask for more information or propose the next step. This can
include a request for a pull request.

## Security Vulnerabilities

Do not disclose a security vulnerability in a discussion or pull request.
Follow the instructions in [SECURITY.md](SECURITY.md).

## Contribution Licenses

By submitting a contribution, you agree to license it under the license that

Read the [license summary](README.md#licenses) before you submit a contribution.
